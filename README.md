# QA Automation Portfolio

This repository is a working demonstration of my approach to quality engineering — 
not a list of skills on a resume, but proof of concept in practice.

## What This Is

A personal QA automation project built with Playwright and TypeScript, integrated 
with GitHub Actions for continuous testing. The goal is straightforward: show that 
I understand not just how to write tests, but how to build a pipeline that runs them 
automatically, reports results clearly, and scales as coverage grows.

## Why I Built It

After 10+ years in QA — spanning manual testing, test planning, API validation, and 
process documentation — I wanted a space to demonstrate the technical side of the 
discipline in a way a resume can't. This repository is that space. It will grow as 
my automation practice grows.

## What You'll Find Here

- Playwright + TypeScript end-to-end test suite
- Page Object Model structure for maintainable, reusable tests
- GitHub Actions CI pipeline that runs tests automatically on every push
- API test coverage alongside UI tests
- Clear, readable test cases that reflect real QA thinking — not just happy paths

## Stack

- [Playwright](https://playwright.dev/)
- TypeScript
- GitHub Actions
- Node.js
